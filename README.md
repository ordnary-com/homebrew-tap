# Ordnary Homebrew tap

```sh
brew install ordnary-com/tap/brim
```

| Formula | |
|---------|---|
| `brim` | [Brim](https://github.com/ordnary-com/brim), the Ordnary programming language, with native builds (macOS on Apple silicon, Linux) |

`Formula/brim.rb` is written by `scripts/homebrew-formula.sh` in the Brim
repository for every release.
